# 07 · 金融信息服务数据分类分级(行业专题)

《金融信息服务数据分类分级指南》,**国信办通字〔2026〕2 号**,2026-06-13 发布。这是 GB/T 43697-2024 通用规则在金融信息服务领域的行业细化。

> **文件位阶(先看这条)**:本文件是六部门以「国信办通字」**印发的指导性文件**,原文措辞为「现印发给你们,请结合实际,认真贯彻执行」,**不是部门规章**,自身不设罚则、归档正文亦未载独立施行日。其约束力来自上位的《数据安全法》《网络数据安全管理条例》。因此下文用「应」而非「必须」。

## 一、先判适用性

> 「适用于在中华人民共和国境内从事金融信息服务的金融信息服务提供者开展数据分类分级和重要数据识别工作」

- 适用主体:**境内从事金融信息服务的金融信息服务提供者**。
- 口径衔接:《指南》衔接《金融信息服务管理规定》——判断自己是否落入监管范围,须回到该规定对「金融信息服务」的定义。
- **范围豁免**:「《指南》不适用于涉及国家秘密的数据和军事数据。」涉密与军事数据走保密/军工专门制度。

判定为「否」的,留存不适用说明;判定为「是」的,立项做分类分级 + 重要数据识别。

## 二、四级分级(比通用规则多一档)

> 「将数据从高到低分为四级,分别为核心数据、重要数据、敏感一般数据、常规一般数据」

| 级别 | 说明 |
|---|---|
| 核心数据 | 最高级 |
| 重要数据 | |
| **敏感一般数据** | 通用三级制里没有的一档 |
| 常规一般数据 | |

「敏感一般数据」的判定门槛:
> 「对经济运行、社会稳定、公共利益有一定影响,或者对组织自身或者公民个体造成重要影响的数据,划分为敏感一般数据」

**实操含义**:内部数据分级模型不能只用「核心/重要/一般」三档。原先笼统归入「一般数据」的资产,要按上述门槛上提到「敏感一般数据」,并相应提高访问控制、加密与出境审查要求。

## 三、三层分类:3 / 9 / 67

> 「一级分类为业务数据、用户数据和企业数据 3 类,在此基础上进一步细分二级分类 9 类、三级分类 67 类」

数据资产目录要能落到 **67 个三级类目**上;盘点结果对不上数量,即说明有缺口。

> 「《指南》附录 A 给出了金融信息服务数据第三级分类 67 类数据的数据描述和示例,以及数据分级的参考最低级别」

**定级时应逐类比对附录 A 的参考最低级别。**

> ⚠️ 归档原文只说附录 A「给出……数据分级的**参考最低级别**」,**未规定**低于参考值需书面说明理由、亦未规定其后果。本库此前的该表述属过度推断,已删除。低于参考级别时怎么办,须向主管部门确认。

## 四、六步流程(每步都有交付物)

> 「数据资源梳理、数据分类、数据分级、形成数据分类分级清单、报送重要数据目录、动态更新管理」

```
① 数据资源梳理 → ② 数据分类(3/9/67) → ③ 数据分级(四级)
→ ④ 形成数据分类分级清单 → ⑤ 报送重要数据目录 → ⑥ 动态更新管理
```

⑤ 报送重要数据目录是流程中的义务动作(非可选),但**报送对象与时限归档正文未载明**,见文末「待核」。另需:
> 「组织开展金融信息服务领域重要数据识别、申报和认定工作」

应预置重要数据申报材料与对口窗口,在监管组织申报时能按期提交,而不是临时补做识别。

## 五、与上位规则的关系

> 「参照国家标准 GB/T 43697-2024《数据安全技术 数据分类分级规则》」

- **上位通用规则**:GB/T 43697-2024(见 [06](06-数据分类分级与合规审计.md))
- **行业特殊规则**:本指南

已按通用标准定级的存量数据,要做一次行业口径复核(尤其是新增的「敏感一般数据」档)。

## 六、多头监管:六部门联合

指南由 **国家网信办、中国人民银行、金融监管总局、证监会、国家统计局、国家外汇管理局** 六部门联合制定。

**实操含义**:报送与问询可能来自六个部门中的任一个,内部责任矩阵要按条线拆分,不能只对接网信办。
