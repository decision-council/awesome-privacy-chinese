# 02 · 国家标准与 TC260 实践指南(2024–2026)

## 先厘清三个主体(常被混为一谈)

| 主体 | 全称 | 角色 |
|---|---|---|
| **SAMR** | 国家市场监督管理总局 | 与国标委共同**发布**国家标准 |
| **国标委 / SAC** | 国家标准化管理委员会 | 国家标准的**主管与归口部门** |
| **TC260** | 全国网络安全标准化技术委员会(旧名「全国信息安全标准化技术委员会/信安标委」) | 网络安全与个保国标的**技术归口**、实践指南编制 |

> TC260 **不是**国标委。国标全文可在 [openstd.samr.gov.cn](https://openstd.samr.gov.cn) 检索,实践指南在 [tc260.org.cn](https://www.tc260.org.cn)。

## 一、已发布的关键国家标准(GB/T)

按用途对号入座——做具体合规动作时,这些标准号是向审计机构或客户证明符合性的凭据。

| 标准号 | 名称 | 用在什么场景 |
|---|---|---|
| GB/T 35273-2020 | 信息安全技术 个人信息安全规范 | 个保基线;⚠️ **正在修订中(草案)**,勿当长期基线锁死 |
| GB/T 39335-2020 | 信息安全技术 个人信息安全影响评估指南 | 做 **PIPIA** 的方法依据 |
| GB/T 42582-2023 | 信息安全技术 移动互联网应用程序(APP)个人信息安全测评规范 | App 合规**自测** |
| GB/T 43697-2024 | 数据安全技术 数据分类分级规则 | 数据**分类分级**与重要数据识别 |
| GB/T 44588-2024 | 数据安全技术 互联网平台及产品服务个人信息处理规则 | 平台类产品的处理规则设计 |
| GB/T 45392-2025 | 数据安全技术 基于个人信息的自动化决策安全要求 | **推荐算法/自动化决策** |
| GB/T 45404-2025 | 数据安全技术 大型互联网企业内设个人信息保护监督机构要求 | 大型平台的**独立监督机构** |
| GB/T 45574-2025 | 数据安全技术 敏感个人信息处理安全要求 | **敏感个人信息**处理 |
| GB/T 45654-2025 | 网络安全技术 生成式人工智能服务安全基本要求 | **生成式 AI 服务**(⚠️ 仅归档标准平台条目,无正文) |
| GB/T 46068-2025 | 数据安全技术 个人信息跨境处理活动安全认证要求 | 出境三路径之「**认证**」 |

**在研(预示下一步义务)**:
- 数据安全技术 个人信息保护合规审计要求(20240896-T-469)—— 推荐性国标,**已到报批稿**;意味着现行 TC260 实践指南是过渡态,后续要升级。
- 儿童手表安全技术要求(20243076-Q-339)—— **强制性**国标,在研(送审稿);做该品类的须提前跟进。

> 以上清单**除 GB/T 45654 外**出自《个人信息保护国家标准体系(2025版)》附件,归档 [`tc260-doc-2025-09-16`](../sources/text/tc260-doc-2025-09-16.txt);GB/T 45654 另据标准平台条目 [`gbt-45654-2025-openstd`](../sources/text/gbt-45654-2025-openstd.txt)。

## 二、TC260 网络安全标准实践指南

「实践指南」不是强制标准,但是监管思路的风向标,落地性强。

| 发布 | 实践指南 | 用途 |
|---|---|---|
| 2025-05-19 | 个人信息保护合规审计要求 | 配套《合规审计管理办法》的操作指引 |
| 2026-08-24 | 个人用户使用人工智能服务安全指南 | 面向 C 端用户的 AI 使用安全建议 |
| 征求意见(202512) | 粤港澳大湾区(内地、澳门)个人信息跨境处理保护要求 | 湾区跨境专项 |

- 合规审计要求(通知):<https://www.tc260.org.cn/portal/article/2/20250519172429>
- TC260 官网(最新指南入口):<https://www.tc260.org.cn/>

## 四、怎么用这些标准
- **定基线**:GB/T 35273(修订中)+ GB/T 43697 定个人信息处理与分类分级的动作基线。
- **对号入座**:做 PIPIA → 39335;敏感个人信息 → 45574;自动化决策 → 45392;出境认证 → 46068;App 自测 → 42582;AI 服务 → 45654。
- **追风向**:实践指南征求意见稿与在研国标预示下一步监管重点(湾区跨境、儿童手表强标、合规审计国标)。
