# 变更记录

本库的数据(归档来源)由 `scripts/fetch_sources.py` 维护;本文件记录内容与结构性变更。

## 2026-08-27(第二轮)— 应抓尽抓:枚举替代搜索

### 新增:`scripts/discover_sources.py`
不再逐个搜索法规,而是**枚举网信办「数据专栏」8 个子专题**——监管自己认定属于该主题的文件全在里面。一次枚举出 80 篇未收录文件,择其 36 篇入库。

两个静默失败点写进了爬虫注释:
- 网信办页面**属性不加引号**(`href=//www.cac.gov.cn/...`),期待 `href="..."` 的正则在满是链接的页面上返回零结果;
- 索引页翻过最后一页仍返回 **200 + 空列表**(不是 404),故翻页必须以「无新链接」为终止条件。

### 新增:可执行义务数据集 + 引文闸
- `data/obligations.csv`:**84 条**可执行义务(门槛/期限/备案/豁免/罚则),每条带来源引文。
- `scripts/verify_quotes.py`:引文**逐字比对归档正文**。引文在不在文件里是可判定的,所以用脚本判定,而不是问模型「你引对了吗」。
- `validate.py` 接入该检查,覆盖 `data/` 下全部 `quote` 与 `evidence_quote`,当前 **132 条全过**。负向测试:编造罚则条文、篡改施行日,**两条都被拒**。
- `validate.py` 另加标题一致性检查:文档 URL 返回门户首页会**直接 fail**,当场逮到 TC260 首页快照(已移除)。

### 归档规模
42 → **77 份**,0 失败;`regulations.json` 21 → **38 条**;`enforcement_cases.csv` 4 → **13 条**。
